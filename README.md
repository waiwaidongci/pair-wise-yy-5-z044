# 手工织锦纹样排版台 · 排产版

直接打开 `index.html` 使用，无需构建。

## 双稿合并

- 画布左侧可切换改稿方：**织造车间** / **打样间**，两方各自保留一版稿。
- 同一格两边都改过时，**保留车间值**，打样稿留冲突（格边红框标记）。
- 冲突在「冲突处理」中确认车间值后才算处理；**冲突未处理不会生成交付包**。

## 批次与排产

- 每批锁定**经向列数、纬向行数、色线容量**（每批允许的色线种数）。
- 用色超出容量时排队，并写明**缺口**（缺多少色线容量）。
- 方案中任一格色号变化后：用色统计、断线风险即时重算；未开织批次的预交付包失效，需**重算**后再开织；**已开织批次保留原快照**，不受方案变更影响。

## 交付包

- 批次开织时冻结快照（网格、用色统计、断线风险）并生成交付包。
- 排队中（有缺口或冲突未处理）的批次不生成交付包。

## 恢复

- 写入采用两阶段并带中断标记；**断网或写入中断后按批次号恢复**，回传记录保留。
- 「回传批次稿」重复回传同一批次号时**只认首次**，后续忽略。
- 旧方案（无批次号的 `zfl31Pattern`）首次打开时**迁成首版（批次 1）**。
- 「模拟写入中断」可演示中断后下次启动的按批次号恢复流程。
